# CIGNAL Learn

中学1年 1学期 中間テスト対策の学習Webアプリ（単一HTMLファイル）。

## 機能

- **LEARN（学ぶ）** — 科目・レベル別の4択学習。間違えたら答えを見て再挑戦、選択肢はランダム配置。
- **TEST** — 10問×5セットの小テスト（英語は聞き取りあり、リアルタイム/一括採点、答えを見る）。
- **要点✓** — 各科目の総まとめ（重要ポイント＋確認クイズ、選択式）。
- **暗記** — フラッシュカード（→で問題→答え→次へ、覚えた/もう一回）。
- **模試** — 教科ごとの総合まとめテスト（5パターン×50分、本物の答案用紙風）。難易度レベル（選択肢→ヒント→通常）で切替・レベルアップ。
- **今日の勉強順** — 学ぶ→要点→暗記→テストへ自動誘導。
- **ゲーム時間メーター** — 達成でゲーム時間が貯まる（リセットで返納）。
- **LENS / ミニブラウザ** — 右パネルで質問・検索（LENSのAI回答は CIGNAL OS 上での実行時のみ動作）。
- **手書き入力 / 分数入力 / ふりがな** — 漢字はマウス手書き、分数は分子分母入力、用語に読み仮名。

対応教科: 英語・数学・国語・理科・社会

## 使い方

`index.html` をブラウザで開くだけ。ビルド不要の単一ファイル。

## 備考

- LENS のAI会話は CIGNAL OS（Tauriアプリ）内でのみ動作します。通常ブラウザでは利用不可。
- 進捗・ゲーム時間は localStorage に保存されます。
- 外部依存: Google Fonts / Google手書き入力API / 検索iframe（いずれもCDN・API、ローカル依存なし）。
